# Список HTML-шаблонов и их назначение

Описание HTML-шаблонов, используемых в проекте.

- **admin_change_password.html**: Форма смены пароля для администратора при управлении пользователями.
- **admin_users.html**: Список пользователей с возможностью изменения роли, редактирования и удаления (админ-интерфейс).
- **base.html**: Базовый шаблон с общим каркасом, навигацией, подключением CSS/JS; остальные шаблоны наследуют его.
- **create_ticket.html**: Форма создания новой заявки/тикета (поля, загрузка вложений).
- **index.html**: Главная страница сайта — приветствие, ссылки на вход/регистрацию и основную навигацию.
- **login.html**: Страница входа (логин/пароль) и обработка ошибок аутентификации.
- **manager_dashboard.html**: Панель менеджера с общей статистикой, фильтрами и таблицей (последние/отфильтрованные заявки).
- **manager_edit_ticket.html**: Страница редактирования тикета менеджером (смена статуса, приоритета, назначение исполнителя).
- **manager_performers.html**: Список исполнителей/сотрудников для назначения на тикеты и просмотра нагрузки.
- **manager_tickets.html**: Полный список тикетов для менеджера с фильтрами, поиском и действиями над тикетом.
- **manager_users.html**: Интерфейс менеджера для просмотра и фильтрации пользователей (компании, контактные данные).
- **profile.html**: Личный профиль пользователя — просмотр и редактирование данных (ФИО, компания, телефон, адрес).
- **register.html**: Страница регистрации нового пользователя с полями профиля и проверкой уникальности.
- **support_dashboard.html**: Панель техподдержки — открытые тикеты, мои в работе, управление взятием/выполнением задач.
- **ticket.html**: Страница просмотра тикета: детали, комментарии, список вложений и форма для добавления комментариев.
- **user_dashboard.html**: Панель обычного пользователя — его тикеты, кнопка создания новой заявки и уведомления.
